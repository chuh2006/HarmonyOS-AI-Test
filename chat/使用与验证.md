# MiniChat

HarmonyOS 手机 AI 聊天应用，使用 ArkTS、ArkUI 和系统 Network Kit。项目根目录为 `chat`，在 DevEco Studio 打开本目录即可编译。兼容和目标 SDK 均为 HarmonyOS 6.1 / API 23。

## 使用

1. 在底部「服务设置」选择服务商，填写 API Key 与 Base URL，保存。
2. 点击顶部模型名称选择模型、思考强度及当前模型支持的选项，点击「完成」。
3. 输入问题并发送。生成时发送按钮切换为停止按钮。失败或停止的最后一轮可以重新生成。
4. 左上角打开历史，右上角新建对话。已有消息时切换模型会创建新会话，每个会话独立记住模型和选项。
5. 四家模型的联网工具统一使用 DeepSeek 的 Search / Fetch API。缺少 DeepSeek 密钥时显示简短提示并以普通对话继续。

思考内容默认折叠。网页工具默认显示查询状态和来源数量，展开可查看查询词与来源链接；网页全文和长摘要仅进入模型上下文。

## 默认接口与能力

| 服务商 | 默认 Base URL | 请求接口 | 思考与输出 |
| --- | --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/anthropic` | `/v1/messages` | Flash、V4 Pro；none / low / high / max；思考块和签名原样回传 |
| OpenAI | `https://api.openai.com/v1` | `/responses` | Astra、6.1 Sol、6.1 Terra、Luna；摘要、加密思考、完整输出项及 phase 持久化 |
| Inception | `https://api.inceptionlabs.ai/v1` | `/chat/completions` | Mercury 3；instant / low / medium / high；默认扩散，也可改为普通流式 |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta` | `/models/{model}:streamGenerateContent?alt=sse` | 3.8 Flash、4 Argon；low / medium / high；摘要与原始 Parts 分别保存 |

OpenAI Astra / Sol 的官方能力不含 `none`，界面提供 low 至 max；Terra / Luna 可关闭思考。四个 OpenAI 模型提供 standard / pro 和 Fast；Ultrafast 仅在 Astra / Sol 显示。请求使用 `store: false`，不依赖服务器保存会话或 `previous_response_id`。

Base URL 可以填写对应表中的根地址，也支持 DeepSeek `/messages`、OpenAI `/responses`、Mercury `/chat/completions` 完整端点。Gemini 可填写版本根地址或模型端点。远程服务要求 HTTPS；localhost / 127.0.0.1 的 HTTP 用于本地联调。DeepSeek 自定义地址会去掉末尾 `/anthropic` 或 Messages 路由，再拼接 `/v1/tools/search`、`/v1/tools/fetch`。

## 实现

- `core/Models.ets`：能力表、选项、会话、展示片段。
- `core/Protocols.ets`：四套请求、流事件解析、完整协议输出与工具结果格式。
- `core/Sse.ets`：SSE 分片、CRLF / LF、多事件、注释与 EOF 缓冲。
- `services/Network.ets`：系统 HTTP 流读取、UTF-8 流解码、取消、连接与响应超时、错误脱敏。
- `services/ChatEngine.ets`：每个会话独立的生成任务、多轮工具循环、重试和协议检查点。
- `services/WebTools.ets`：Search / Fetch，最多 4 个并发调用、每轮最多 16 个调用、最多 8 轮工具执行；调用 ID 去重并校验参数一致性。
- `services/Store.ets`：Asset Store 保存密钥；完整会话以 UTF-8 文件原子替换、fsync 和备份保存。
- `pages/Index.ets`、`components/TurnView.ets`：聊天界面、弹层、可折叠思考和工具卡片。

Mercury 的扩散正文按整帧替换，普通流按增量拼接；每个工具轮次创建独立输出阶段。终止事件的 null / 空正文不会抹去最后一帧。Gemini 的原始 Part 按顺序保存，带签名的空文本 Part 也保留，工具响应保留服务端提供的调用 ID。

停止会销毁当前模型及工具请求，并阻断后续循环；切换会话后回调只更新其原会话。完成的工具请求和结果成对写入协议检查点。未完成输出另存为草稿，冷启动后标为已停止，后续请求回放完整检查点；重试重新执行该用户轮次。

模型请求连接超时 20 秒、无数据超时 90 秒、总时限 5 分钟；工具无数据超时 45 秒、总时限 60 秒。搜索结果最多 5 条，每条正文最多 16,000 字符；抓取正文最多 64,000 字符，截断会向模型标明。

## 构建与测试

macOS 已安装 DevEco Studio 时：

```sh
./scripts/build.sh
node --test tests/core.test.cjs
```

`DEVECO_STUDIO_HOME` 可指定其他 DevEco 安装位置。构建产物：

```text
entry/build/default/outputs/default/entry-default-unsigned.hap
```

当前项目未配置签名。模拟器支持安装该 unsigned HAP；真机请在 DevEco Studio 的 Signing Configs 中完成签名配置。

核心测试直接转译并加载应用 `.ets` 源码，平台网络、Asset Store 和文件 API 通过适配器替换。覆盖分片解码、四家协议、工具并发及重复调用、停止、重试、历史回放、超长历史、写入失败及备份恢复。设备检查使用真实 Network Kit、真实 Asset Store 与真实文件系统。

`scripts/mock_provider.cjs` 是独立的本地协议联调服务，未被应用导入；只接受显式测试用凭据。`scripts/device_probe.py` 是 HDC UI 检查辅助脚本。联调时仅在测试模拟器中填写测试地址与测试凭据，测试结束后恢复官方地址并移除测试密钥。

实际执行结果及验收范围见 [验证记录](验证记录.md)。
